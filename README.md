## Descripción del Proyecto
Este proyecto es una hoja de vida interactiva y portafolio profesional desarrollado como SPA (Single Page Application). Implementa un diseño modular y responsivo basado en maquetación de Figma, utilizando arquitectura de componentes reutilizables.

## Tecnologías Utilizadas
- **Framework:** Next.js (con React)
- **Lenguaje:** TypeScript
- **Estilos:** TailwindCSS
- **Íconos:** Iconify / FontAwesome (SVG)
- **Despliegue:** Vercel

## Instrucciones de Ejecución Local
Para ejecutar este proyecto en tu entorno local, sigue estos pasos:

1. Clonar el repositorio.
2. Instalar las dependencias con: `npm install`
3. Iniciar el servidor de desarrollo con: `npm run dev`
4. Abrir [http://localhost:3000](http://localhost:3000) en el navegador.
